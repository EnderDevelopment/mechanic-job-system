# Mechanic Job System

A complete mechanic job system for FiveM with vehicle repair and management features.

## Features

- Vehicle repair with cost and time settings
- Job-specific blips and vehicle spawns
- Database integration for tracking vehicle repairs

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start MechanicJobSystem` to your server.cfg file
4. Import the database.sql file into your MySQL database

## Usage

### Commands

There are no player commands for this script. The mechanic job features are accessed through the in-game menu.

### Permissions

This script does not require any special permissions. Players with the mechanic job will have access to the job-specific features.

## Configuration

The script can be configured in the `config.lua` file. You can adjust the blip settings, vehicle spawns, repair cost, and repair time.
